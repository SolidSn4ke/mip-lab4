## Цель работы

  Снизить уровень шума на синтезированном изображении, полученном методом трассировки путей, сохранив при этом физическую корректность освещения и четкость границ объектов.

## Задание

Реализовать метод билатеральной фильтрации синтезированного изображения. Фильтр должен эффективно подавлять шум в однородных областях, но предотвращать размытие на границах объектов (edge-preserving smoothing).

Для реализации фильтрации необходимо использовать следующие данные о точке первого пересечения луча со сценой:

- Итоговая яркость (цвет)
- Глубина (расстояние до объекта)
- Индекс объекта сцены
- Нормаль к поверхности

## Ход работы

В ходе выполнения работы были реализованы следующие этапы:

  1. Модификация конвейера рендеринга:
    - Введен новый тип данных RenderPixel, который хранит не только итоговый цвет, но и вспомогательную геометрию (глубину, нормаль, ID объекта).
    - Создана функция trace_first_hit, которая позволяет извлекать эти данные в момент первого пересечения луча с геометрией, сохраняя при этом рекурсивный расчет
  глобального освещения.
  2. Обновление сервиса рендеринга:
    - Класс SceneRenderer был переведен с генерации обычного HDR-изображения (`Image<Color>`) на генерацию изображения с данными о пикселях (`Image<RenderPixel>`).
  3. Реализация билатерального фильтра:
    - В PostProcessor реализован алгоритм фильтрации, который объединяет пространственную близость пикселей с их геометрическим сходством.
    - Внедрена проверка objectId для обеспечения абсолютной сохранности границ между разными объектами.
    - Реализована нормировка весов (арифметическое среднее) для сохранения энергетического баланса яркости.

## Алгоритм

Для подавления шума используется билатеральный фильтр. Значение нового пикселя $g(p)$ вычисляется как взвешенное среднее соседних пикселей $q$ в радиусе $R$:

$$g(p) = \frac{1}{W_p} \sum_{q \in S} f(q) \cdot G_s(|p - q|) \cdot G_r(\Delta p, \Delta q)$$

1. Пространственный вес (Spatial Weight).  
  Определяет влияние соседа в зависимости от расстояния между пикселями:
  $$G_s(|p - q|) = \exp\left(-\frac{|p - q|^2}{2\sigma_s^2}\right)$$

2. Вес диапазона (Range Weight).  
  Определяет сходство геометрии точек. Если точки сильно различаются по глубине или нормали, вес стремится к нулю:
  $$G_r = \exp\left(-\frac{(depth_p - depth_q)^2}{2\sigma_d^2} - \frac{(1 - \vec{n}_p \cdot \vec{n}_q)^2}{2\sigma_n^2}\right)$$

3. Сохранение границ (Edge Preservation).  
  Для предотвращения размытия между разными объектами вводится жесткое условие:
  $$\text{если } id_p \neq id_q \implies \text{вес} = 0$$

4. Нормировка.  
  Сумма всех весов $W_p$ используется для нормировки итогового цвета, что предотвращает появление темных или слишком ярких пятен:
  $$W_p = \sum_{q \in S} G_s(|p - q|) \cdot G_r(\Delta p, \Delta q)$$
